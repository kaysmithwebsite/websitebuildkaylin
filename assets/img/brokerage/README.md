# Official brokerage brand assets

Drop the official RE/MAX logo here as **`remax-logo.svg`** (or `.png`).
`build.py` looks for it automatically on every build. No config edit is needed:
the moment the file exists, the placeholder slot in the footer is replaced by
the real logo at the size the layout already reserves for it.

Accepted filenames, in order of preference:

    remax-logo.svg
    remax-logo.png
    remax-logo.webp

## Why this build does not draw the logo

The RE/MAX balloon and wordmark are registered trademarks of RE/MAX, LLC. Brand
standards govern their proportions, colour, clear space and minimum size, and a
redrawn or recoloured approximation would breach them. Recolouring the mark to
navy to match this site's palette is specifically not permitted.

Kaylin, as a registered Broker with a RE/MAX brokerage, is licensed to use the
official assets. Request them through the brokerage or the RE/MAX brand centre
and place the supplied file here unmodified.

Until then the brokerage is identified in text throughout the site, which is
what the regulatory disclosure requires. The logo is a brand requirement, not a
disclosure requirement, so nothing is out of compliance in the meantime.
